## Dataset
- **Source**: Global Findex Database 2025 (World Bank)
- **Note**: The underlying raw Findex microdata is proprietary and **not included** in this repository. Place the raw CSV(s) under `data/raw/` before running the pipeline.

## Codebook
The file `data/codebook/Findex_2025_codebook.csv` contains variable names, assigned categories, and descriptions to help interpret the dataset.

## Quick start (reproducible, bash)
1. Clone the repo and enter it:
```bash
git clone git@github.com:aididshariff/MobileMoney-Adoption-Analysis.git
cd MobileMoney-Adoption-Analysis
```

2. Create and activate a virtual environment (bash):
```bash
python -m venv .venv
source .venv/bin/activate
```

3. Install dependencies:
```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

4. Add the proprietary raw data (not included) into `data/raw/` (e.g. `global_findex.csv`).

5. Run the pipeline (this will create `outputs/` and `data/processed/tableau_ready_data.csv`):
```bash
python -u scripts/run_pipeline.py
```

6. Inspect outputs in `outputs/` and the Tableau-ready CSV in `data/processed/`.

Notes:
- If you get a DtypeWarning reading the raw CSV, open the file in a text editor or use `pd.read_csv(..., low_memory=False)`; the pipeline currently sets a robust default but you can set explicit dtypes if needed.

## Short project summary (findings)
This analysis compares OLS and a Random Forest regressor to predict Mobile Money Adoption (indicator `mobileaccount_t_d`). Key findings (from the final run):
- OLS (VIF-corrected baseline) achieved R^2 ≈ 0.1182 — useful for inference but a poor predictor.
- Random Forest achieved R^2 ≈ 0.6804 — strong predictive performance.
- Top predictive features (RF importance): `pop_adult`, `account_t_d`, `internet`, `year`.

Interpretation: non-linear relationships (and interactions) are important — ensemble methods capture these patterns much better than a single linear model.
